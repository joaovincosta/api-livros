# 📚 API de Livros — SW-II

Este repositório apresenta o desenvolvimento de uma **API de livros**, criada como projeto da disciplina de **Sistemas Web II (SW-II)**, ministrada pelo professor **Anderson Vanin**. O projeto é desenvolvido ao longo de **quatro etapas, com diferentes datas de entrega**, constituindo um dos principais requisitos para a composição da nota na disciplina.

A aplicação tem como objetivo colocar em prática os conhecimentos adquiridos durante as aulas por meio do desenvolvimento de uma **API integrada a um banco de dados e a uma interface web simples**, utilizando **Python, MySQL, HTML e CSS**.

Entre os principais requisitos estabelecidos para o projeto estão:

O projeto deve contar com um banco de dados composto por **no mínimo 5 tabelas**, uma API com **CRUD completo**, contemplando as operações **GET**, **GET por ID**, **POST**, **PUT por ID** e **DELETE por ID**, além do desenvolvimento de uma **interface simples** para interação com a aplicação.
